[![MATLAB](https://img.shields.io/badge/MATLAB-R2020b%2B-blue.svg)](https://www.mathworks.com/products/matlab.html)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

[![Status](https://img.shields.io/badge/Status-Research%20Code-orange.svg)]()

A MATLAB implementation of an evidential network reconstruction framework that infers hidden network structures from multiple independent SIS epidemic time series using **Dempster-Shafer evidence theory**.

The framework reconstructs an unknown adjacency matrix from binary node-state observations, where each node is either susceptible or infected at each time step. Multiple epidemic time series are treated as independent evidence sources and fused to obtain a robust link-confidence matrix.

---

## 📌 Overview

Network reconstruction from dynamical observations is a central problem in complex network analysis. This repository provides a reconstruction framework for inferring the underlying network topology from SIS epidemic time series.

Given several independent binary time series generated by SIS spreading dynamics on an unknown network, the method estimates whether each pair of nodes is connected. The reconstruction procedure is based on three main ideas:

1. **Evidence extraction from state transitions**
   Node-state transitions are used to construct evidence supporting the existence or non-existence of links.

2. **Basic Probability Assignment (BPA)**
   For each candidate node pair, evidence is represented as belief masses assigned to:

   * link exists,
   * link does not exist,
   * uncertainty.

3. **Dempster-Shafer evidence fusion**
   Multiple independent epidemic time series are fused using Dempster’s rule of combination to obtain a final link-confidence matrix.

The final reconstructed network is obtained by applying an adaptive decision threshold.

---

## ✨ Key Features

* Reconstruction of hidden network structure from SIS epidemic time series
* Multi-source evidence fusion via **Dempster-Shafer evidence theory**
* Basic Probability Assignment construction for link existence, link absence, and uncertainty
* Automatic threshold selection using two decision rules:

  * **DR-MR**: Decision Rule based on Minimum Robustness
  * **DR-MS**: Decision Rule based on Maximum Similarity
* Infection/recovery parameter estimation utilities
* KL-divergence based validation of reconstructed network dynamics
* Parallel computation using MATLAB `parfor`
* Example network data included for quick testing
* Modular MATLAB implementation for easy modification and extension

## 🧠 Methodological Pipeline

The overall reconstruction pipeline is:

```text
Multiple SIS epidemic time series
        ↓
State-transition statistics
        ↓
Basic Probability Assignment construction
        ↓
First-level evidence fusion
        ↓
Multi-source Dempster-Shafer fusion
        ↓
Link-confidence matrix
        ↓
Threshold selection
        ↓
Reconstructed adjacency matrix
        ↓
Validation by topology and dynamics
```

## 🧪 SIS Epidemic Time Series

The SIS model contains two node states:

* `0`: susceptible
* `1`: infected

At each time step:

1. infected nodes may infect susceptible neighbors;
2. infected nodes may recover and become susceptible again;
3. the binary state vector is recorded.

The observed time series has the form:

```matlab
TIME(t, i)
```

where `t` is the time index and `i` is the node index.

---

## 🧩 Evidence Representation

For each candidate node pair, the method assigns three belief masses:

```text
T : evidence supporting link existence
F : evidence supporting link absence
U : uncertainty
```

These masses satisfy:

```text
T + F + U = 1
```

The evidence matrices are then fused across multiple independent SIS time series.

---

## 🔄 Dempster-Shafer Evidence Fusion

Given two evidence sources:

```text
m1 = (T1, F1, U1)
m2 = (T2, F2, U2)
```

the conflict coefficient is:

```text
K = T1 * F2 + T2 * F1
```

Dempster’s combination rule is:

```text
T = (T1*T2 + T1*U2 + T2*U1) / (1 - K)

F = (F1*F2 + F1*U2 + F2*U1) / (1 - K)

U = (U1*U2) / (1 - K)
```

This fusion process is applied to all candidate node pairs.

---

## 🎯 Threshold Selection

The fused matrix provides a continuous confidence score for each possible link. A binary reconstructed network is obtained by thresholding the confidence matrix.

This repository includes two threshold decision rules.

### DR-MR: Decision Rule based on Minimum Robustness

DR-MR selects a threshold that preserves a sufficiently large connected backbone in the reconstructed network.

This is useful when the reconstructed network is expected to be globally connected or to contain a dominant connected component.

### DR-MS: Decision Rule based on Maximum Similarity

DR-MS selects the threshold that maximizes the similarity between infection patterns generated by the reconstructed network and those observed in the original time series.

The similarity is computed using the Jaccard similarity of newly infected nodes.

---

## 📊 Evaluation Metrics

The repository provides several evaluation and validation tools.

### 1. Topological Similarity

If the ground-truth network is known, reconstruction quality can be evaluated by comparing the reconstructed adjacency matrix with the true adjacency matrix.

A common metric is the Jaccard similarity:

```text
ACC = |E_rec ∩ E_true| / |E_rec ∪ E_true|
```

where:

* `E_rec` is the edge set of the reconstructed network;
* `E_true` is the edge set of the ground-truth network.

### 2. Infection Jaccard Similarity

The function `compute_infection_jaccard.m` compares newly infected nodes between two epidemic processes.

This is mainly used in DR-MS threshold selection.

### 3. KL-Divergence Validation

The file `KL.m` computes the Kullback-Leibler divergence between epidemic time series distributions.

This can be used to evaluate whether the reconstructed network preserves the spreading dynamics of the original network.

Because SIS simulations are stochastic, results may vary between runs.

To make results reproducible, set the random seed before running the main script:

```matlab

main_Code;
```

When using `parfor`, exact reproducibility may require additional control of random streams across parallel workers.

## 🧰 Troubleshooting

### 1. `parfor` error

If MATLAB reports that a variable cannot be classified in a `parfor` loop, use one-dimensional temporary arrays inside the loop and reshape the result after the loop.

Example:

```matlab
ACC_vec(job) = ACC_value;
```

Then reshape:

```matlab
ACC_all = reshape(ACC_vec, C1, C2, C3);
```

### 2. Empty time series

If an epidemic dies out too early, the generated time series may be empty or invalid.

Possible solutions:

* increase the infection rate;
* decrease the recovery rate;
* increase the number of initial infected nodes;
* reduce the required time-series length;
* repeat the simulation more times.

### 3. Poor reconstruction accuracy

Possible reasons include:

* insufficient time-series length;
* epidemic process quickly reaches extinction or saturation;
* infection and recovery parameters are not suitable;
* the network is too dense or too sparse;
* threshold selection is not appropriate;
* too few independent time series are used for evidence fusion.

### 4. Memory issues

For large networks, evidence matrices of size `N × N` can consume significant memory.

Possible solutions:

* use sparse matrices where possible;
* reduce the number of repeated simulations;
* process candidate links in batches;
* use smaller test networks first.
